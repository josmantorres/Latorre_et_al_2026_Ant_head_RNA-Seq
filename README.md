# RNA-seq Analysis of Carbohydrate Restriction in *Linepithema humile*

## Overview

This repository contains the R script used to analyse head transcriptomes from workers of the Argentine ant, *Linepithema humile*, exposed to carbohydrate restriction.

The study investigates transcriptional responses to a low-sucrose diet and their potential relationship with changes in feeding behaviour, carbohydrate metabolism, and other physiological processes.

The analysis compares gene expression between workers fed a normal diet and workers exposed to a low-sucrose diet.

## Experimental Design

The experiment includes two groups of workers:

- **Control:** workers fed a normal diet.
- **Treated:** workers exposed to a low-sucrose diet.

RNA-seq was performed on head tissue. The dataset contains 10 independent biological samples, with five samples per condition.

| Treatment | Sample IDs | Number of samples |
|---|---|---:|
| Control | C1, C2, C3, C4, C5 | 5 |
| Treated | T1, T2, T3, T4, T5 | 5 |

## Statistical Analysis

### Input data

The analysis requires two input files:

- `Raw_counts.txt`: raw gene-level RNA-seq counts. The first column contains gene identifiers, and the remaining columns contain counts for individual samples.
- `experimental_design.txt`: sample metadata, including sample identifiers (`Sample`) and treatment assignments (`Treatment`).

The script checks that gene identifiers are unique, counts are non-negative integers, and sample identifiers match between the count matrix and metadata.

### Regularized log transformation

The raw count data are transformed using the regularized logarithm (rlog) transformation implemented in DESeq2.

```r
rlog_data <- rlog(dds, blind = TRUE)
```

The transformation is performed on the dataset before low-expression filtering. Consequently, `Rlog_values.txt` contains transformed expression values for all genes in the original count matrix.

The rlog matrix is intended for downstream exploration and visualization. It is not used as input to the differential expression model.

### Low-expression filtering

Low-expression genes are filtered using the `HTSFilter` package with `s.len = 100`.

The filtered count matrix is used for the differential expression analysis.

### Differential expression analysis

Differential expression is analysed with DESeq2 using a negative binomial generalized linear model and the Wald test.

The design formula is:

```r
design = ~ Treatment
```

`Control` is defined as the reference level. The contrast is:

**Treated vs Control**

where Treated represents the low-sucrose diet.

- A positive log2 fold change indicates higher expression in the low-sucrose group.
- A negative log2 fold change indicates lower expression in the low-sucrose group.

Results are extracted with `independentFiltering = FALSE` and `cooksCutoff = TRUE`.

### Log2 fold-change shrinkage

Log2 fold changes are shrunk using `apeglm` through the DESeq2 `lfcShrink()` function.

The output table contains the shrunken log2 fold-change estimates and the associated DESeq2 result statistics. The analysis does not apply an additional log2 fold-change threshold in the `lfcShrink()` call.

The criteria used to define the final set of differentially expressed genes should be interpreted according to the manuscript's stated significance threshold and filtering procedure.

## Output Files

The script generates exactly two output files in the `results/` directory.

| File | Description |
|---|---|
| `DESeq2_Treated_vs_Control_apeglm.txt` | Differential expression results for Treated vs Control, including apeglm-shrunken log2 fold changes and associated statistical results. Only genes retained by HTSFilter are included. |
| `Rlog_values.txt` | rlog-transformed expression matrix for all genes in the original count matrix, before HTSFilter. |

The `results/` directory is created automatically when the script runs. Output files are generated by the script and do not need to be committed to the repository unless you intend to distribute the results alongside the code.

## Running the Analysis

Run the script from the repository root directory:

```bash
Rscript scripts/01_DESeq2_carbohydrate_restriction.R
```

The input files must be located in the `input/` directory and must follow the formats described above.

## Software Requirements

The analysis uses R and the following packages:

- `DESeq2  v.1.42.1`
- `HTSFilter v.1.28`
- `apeglm  v.1.24`

## Reproducibility and Data Availability

The analysis uses raw integer counts for differential expression testing. The rlog-transformed matrix is provided as a separate output for exploratory analyses and visualization.

The raw sequencing data and associated metadata should be linked to their public repository accession, if available, in the associated manuscript or repository documentation.
